# 数据卡

全部场景为AI辅助、程序自编的虚构API资料；没有真实用户、账号、密钥或私有项目。模型未用于生成这套语料。文本、项目、路径均为模拟，不可当作真实接口文档。随项目按MIT提供这些自编测试资料；上游模型权重不在此数据许可内。

`dev/streams.jsonl`：4条流、48事件、72常规探针、8个配对诊断执行。`test/streams.jsonl`：8条流、96事件、144常规探针、16诊断执行。每流12事件。8条test流共40种唯一常规任务输入（忽略task_id），同一锚点会重复，不能用执行数代替独立问题数。

生成器：`python -m evaluation.build_data`。改动模式包括登录路径迁移、认证字段更名、立即/延后授权纠错、未授权纠错、晚到旧资料、另一项目、否定或条件待复核。12流共享骨架；不能声称只凭这些流获得对真实场景的统计独立证据。dev/test是工程划分，没有盲测访问控制或双人独立标注。

`evaluation/labels/truth.jsonl`单独保留评分规格、可回答性和更新动作预期。记忆库和规划器不加载它。执行器在规划返回后评分；原始事件中指定的target_id是公开纠错依据，不是隐藏真值。

动作标签：duplicate=同范围同值重复；supplement=新属性；coexist=不同项目/版本或不重叠时间；conflicts=同范围不同值无替代依据；supersedes=本地授权、明确目标、同范围定向替代；pending=证据/范围不足或未授权。标签由构造逻辑决定，尚未经人工复核。不能把事件级精确动作匹配称作独立标注宏F1。

工具隐藏规格不向Agent传递；冲突/无知识正确行为为clarify。所有probe问答和反馈都不进入下一检查点。
