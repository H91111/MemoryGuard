# 演示脚本

约3分20秒，视频为真实本机浏览器交互，字幕说明，无配音；API/项目均为模拟。不把演示案例计入合成评测指标。

1. 展示工作台与本地运行状态，说明围绕开发API知识更新。
2. 新建会话，依次写入v1与重复描述，执行v1登录。
3. 加入v2，执行v2；加入Beacon，验证项目隔离。
4. 写入未经证实的另一登录路径，执行v2看到澄清。
5. 维护者定向纠错，v2恢复；再执行v1验证保留。
6. 回放第5步看到冲突，确认未来纠错没有倒灌。
7. 展示来源/决策链、原始结果和五方法加两消融。
8. 说明字符基线已足够、BGE没有额外收益，生成模型与真人验证尚未完成。

手动演示：启动工作台，使用“重新体验六步演示”和“写入下一步”。完整视频由`scripts/record_demo.cjs`录制，需Playwright/Chrome/FFmpeg；这些为制作工具，不是产品使用依赖。
