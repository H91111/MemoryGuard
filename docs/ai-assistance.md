# AI 辅助说明

v0.2.0 在用户提供的 MemoryGuard-v0.1.0 源码基础上，由 Codex 协助阅读、修改与验证。用户确认最终用途为可演示、可交付的软件成品。

本轮 AI 参与：影响预检/门控、会话与恢复、界面、Python 3.11 兼容修复、检索预算修复、自动检查、浏览器操作验证、离线合成回归和文档打包。

v0.2.0 的默认应用使用规则提取和确定性工具规划，其历史回归没有生成模型参与。

2026-10-28 day1 推进由 Codex 协助完成模型规划适配、三策略连续学习实验、合成数据与独立评分、测试、运行说明及参赛材料。新增 `ChatPlanner` 的应用运行时推理与这些开发辅助活动分别记录。真实执行情况以 `output/evaluation-day1/` 的配置、逐次请求/响应和汇总为准，不能仅凭接口代码声明模型已经运行。

模型权重不训练，记忆更新属于非参数适应。样例、评分与报告由开发过程共同编写且可见，未开展真人访谈、独立盲标或真实业务 API 验证。自动测试及模型模拟评分不等于团队人工审核；最终用途、成果归属、第三方来源及比赛提交需团队按实际情况审核。没有从本地文件推断报名、缴费、公开发布或提交成功。
