## 学习与控制的关系

LLA 在这里采用非参数外部记忆适应。固定的任务规划器调用 retrieve；每次学习改变外部记忆，进而改变后续任务行为。负影响控制位于记忆追加前和工具规划前。

1. prepare 规范化事件并执行一次提取。
2. fork 使用完整审计内容恢复私有内存库，保持检查点前缀一致。
3. 私有库 ingest 应用与正式库相同的范围、冲突、授权替代规则。
4. compare 在前后状态执行相同任务，不调用外部工具、不写反馈。输出保留/阻断/参数变化/恢复/仍不可用。
5. 提交对象包含原状态摘要、冻结候选和结果指纹。commit 在同一库锁下验证摘要、风险确认及对象一致性，然后以冻结候选调用 ingest。
6. 网页缓存的预检令牌与会话绑定，过期或切换会话失效；避免旧界面的确认应用到新状态。

确认不会让冲突事实自动获胜。冲突仍在正式库共存，规划器在截断上下文之前检查未决冲突，优先澄清。

## 保留证据与预算

逻辑事实以项目、版本、主体、属性、有效区间划分。检索阶段每个逻辑事实保留一份代表证据并记录总证据数，避免重复观察无限占据上下文。审计库、事实检查与导出保留全部原文及跨度。上下文预算仍为UTF-8字节，不冒充真实模型token。

## 会话与恢复

SQLite 存不可变事件和审计关系；旁置 JSON 保存会话名称、相对数据库文件名、当前会话ID，临时文件后原子替换。恢复检查点创建独立新库；原库不删除。导入在事务内核对完整状态摘要，失败回滚、关闭连接，不切换当前会话。会话不是用户权限边界。

## 评测边界

沿用8条开发者可见的合成测试流；3个离线方法、480次探针执行。方法统一规则提取和确定性规划，治理方法使用代表证据压缩，原样基线使用全部观察。这是明确披露的策略差异，不声称它来自神经模型收益。

页面实时监测无隐藏真值，报告的是行为变化。离线评测在规划后才使用独立模拟规格评分。相邻旧任务成功→失败只计入前一步成功的配对，分母为0报告null；同时呈现多余澄清以避免全拒答策略显得有优势。科研结论仍需要真实授权数据、独立标注和真实Agent对照。
