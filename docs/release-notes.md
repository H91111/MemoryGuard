# v0.2.0 交付变更

日期：2026-10-26。根据用户确认，以可演示、可交付的单机软件为目标。

## 新增

- impact.prepare / commit：独立副本试写，冻结提取结果，按任务比较行为，原状态哈希绑定，风险确认。
- impact.compare / fork / history：两个状态对比、检查点独立分支、前缀逐步巡检。
- Workspace：持久会话索引、新建/切换/恢复/导入，重启回到原会话。
- 网页：学习预检与保存两步流程、负影响监测、会话管理、自定义项目/版本、有效日期。
- 评测：同时呈现冲突强答与多余澄清；原始 JSON 记录相邻旧任务回退及跨范围引用计数。
- 示例：可直接运行的 LLA 学习门控集成。

## 修复

- Python 3.11 不支持原 `_checkpoint` f-string 表达式中的转义，导致整个包无法导入；已拆分计算。
- 逻辑事实的重复证据可无限占据预算，挤掉其他必要字段；检索上下文使用一份代表证据，完整证据仍在审计库。
- 回放完整性验证从提交后改为事务内检查，失败回滚并关闭连接。
- 启动脚本等本地服务绑定后再打开浏览器；区分不同目录的工作区与端口占用。
- 原网页只保留新会话文件而无恢复入口、重启会回原始库；改为可切换的持久会话。
- 自定义项目未配置模拟器规格时明确标注计划未验证，不报假成功或混作真实调用失败。

## 兼容与限制

保留原有审计包 v1 格式、规则版本与直接 ingest 接口。网页默认规则提取、字符检索；可选模型需要用户自行配置。无需第三方依赖即可启动核心。

自动任务覆盖 API 登录路径/认证字段；Python 可指定任务与时间，非任意通用技能。预检比较输出行为，没有隐藏真值，不把正常纠错或保守澄清称为模型遗忘。网页巡检上限200事件、100范围，预检令牌15分钟到期。导入上限9.5MB（服务请求体10MB）；本机操作者共享 maintainer 来源策略，不是身份验证。

没有完成真人试用、盲标、通用 LLM 对照或真实业务执行。旧版的神经模型结果与视频未作为本轮成果复用；本轮验收见 output/acceptance 和 output/evaluation-v020。
