# 冻结协议：synthetic-regression-v1

本协议在首次运行评测前编写。数据为程序自编、开发者可见的合成回归样本，没有独立人工盲标或外部用户验证。4条dev、8条test仅是固定工程划分；场景共享构造骨架，不代表12个统计独立真实项目。不通过这些结果宣称研究优越性。

- 每流12个观察事件；每2步3个常规探针：固定v1锚点、当前版本、边界任务。每流另在一次纠错前后执行2个隔离诊断。
- 输入、项目/版本和来源元数据对全部方法可见。所有方法使用同一 RuleExtractor 候选缓存及同一确定性规划器。没有LLM生成调用，不将执行次数称作模型调用数。
- B0无记忆；B1同范围普通BGE向量原样记忆；B2同范围按观察顺序最近优先；B3同范围治理+字符TF-IDF；Ours治理+字符/BGE联合检索；A1去掉检索范围过滤；A2同范围联合检索但去掉更新治理。
- B1采用范围过滤，是比完全忽略元数据更强的简单基线。B2不会按事实正确性或授权来源重排。两者共享来源权限信息，但不实现被比较的治理策略。
- BGE固定为BAAI/bge-small-zh-v1.5@7999e1d3359715c523056ef9478215996d62a620。CLS池化、L2归一化、最长512 tokens、查询加官方中文检索指令。字符1—3 gram TF-IDF，联合得分二者均值。分数不是置信概率。
- top-k=8。上下文上限2048 UTF-8字节，作为保守的token上界代理；不是实际模型token统计。所有方法按相同JSON事实格式计费。冲突检测在上下文截断前完成。
- 规划器只能接收任务和检索上下文；标签/独立规格只在其返回后交给评测器评分。探针前后状态哈希必须一致。逻辑隔离不是恶意代码的OS沙箱。
- 每方法每流重置。每个探针新建无状态规划调用，不回写问答或工具反馈。BGE缓存可跨方法复用，报告耗时明确为混合缓存，不宣称冷启动速度。
- 主指标：可回答任务成功数/可回答任务数；同时报告正确澄清、错误强答、多余澄清、锚点保持、过期值误用、纠错前后配对诊断和按流宏平均。
- 旧锚点只计应始终有效的v1任务。冲突时正确行为是澄清，即使模拟器知道规格也不要求强答。
- 所有方法维护同一审计镜像以验证前缀；原始策略不读取其治理结果。learning.jsonl中的时间为公共审计写入成本，不能用于宣称各策略原生写入成本差异。
- 不预设提升百分比。若字符规则已经解决全部样本，明确报告embedding没有带来增益。不开启语义依赖时仅运行B0/B2/B3，不伪造B1/Ours。
- 尚未实现正式的人类更新标签混淆矩阵/宏F1、人工证据支持抽样、独立真实场景或原生SimpleMem/Graphiti对照。当前更新指标为自编预期动作的事件级精确匹配。

复现：`python -m evaluation.build_data`，`python -m memory_guard evaluate --semantic --split test`。实际配置、输入SHA256和环境在运行前写入config.json。软件修复后的重跑均视为探索验证，不称测试独立。
